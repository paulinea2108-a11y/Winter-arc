# Winter Arc

Le Winter Arc de Pauline : une page avec une montagne 3D en haut et un suivi des objectifs par onglets en dessous.

## Lancer en local

```bash
node server.js
```

Puis ouvrir http://localhost:5180 (pour changer de port : `PORT=3000 node server.js`).

Aucune dépendance à installer, il faut juste Node.js. En local, les progrès sont enregistrés dans le navigateur (`localStorage`). Publiée comme artefact Claude, la page les synchronise aussi avec le compte.
